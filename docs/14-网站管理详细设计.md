## 1. 目标与范围

P7 在写操作内核（docs/09）与 P4 只读资源基础上，交付**网站管理**；WEBSITE+ 在 P7 之上补齐建站与常用运维入口：

1. 真实只读探测 + 1Panel v2.3.2 源码/前端 API 核对（写接口不在真实节点执行）；
2. 只读查询服务 `WebsiteService`：节点网站列表（含 1Panel 自定义分组）、网站详情、域名、反向代理、HTTPS/SSL 证书安全元数据、PHP 运行环境；WEBSITE+ 增加建站可选项、安装预检查、ACME 账户；
3. 写操作处理器（复用内核确认/审计/批量语义）：
   - 网站：`website.start` / `website.stop` / `website.update` / `website.php_version` / **`website.create`**
   - 域名：`domain.create` / `domain.update` / `domain.delete` / **`domain.primary`**
   - 反向代理：`proxy.create` / `proxy.update` / `proxy.delete` / `proxy.status`
   - SSL：`ssl.apply` / `ssl.deploy` / **`ssl.request`** / **`ssl.disable`**
4. Web 只读查询端点 `/api/websites/*`（Admin only）；WEBSITE+ 增加 `create-options` / `precheck` / `acme-accounts`；
5. Blazor 页面 `/websites`：节点 + 分组树/筛选、网站列表、详情抽屉（基础信息/域名/反代/HTTPS/证书/PHP 版本）、危险操作走内核确认；WEBSITE+ 增加**建站向导**、详情补全、设主域名、申请证书、关闭 HTTPS；
6. 网站日志入口链接（日志页面由 P10 提供）：`/logs?type=website&nodeId=<guid>&website=<primaryDomain>`；
7. 单元/契约/集成测试（预览→强确认→执行→审计全链路、只读服务、页面渲染）。

**非目标（仍不做）**：删除网站、Nginx 配置源码编辑、伪静态/重定向/CORS/认证/限流/负载均衡等 1Panel 高级配置、备份/恢复、网站文件管理、日志内容展示（P10）。WEBSITE+ 的建站仅覆盖 `static/runtime(PHP)/proxy/subsite` 四类，不含 `deployment`（应用商店部署）与 `stream`（流媒体）向导。

### 2.4 探测限制与注意点

1. 真实节点无网站：列表/详情/域名/反代/HTTPS 的**成功响应**由假面板按 1Panel 字段构造并做契约测试；写接口从未在真实节点执行。
2. `websites/search` 的 `orderBy/order` 为必填，且 `order=null` 是合法值；本实现固定 `created_at` + `descending`。
3. 网站列表接口**不返回分组字段**；分组归属通过 `groups/search` 得到分组列表后，按 `websiteGroupId` 逐分组查询（与 P4 资源树一致）。
4. SSL 相关响应包含证书私钥/PEM：客户端 DTO 有意不声明、且不使用 `JsonExtensionData`，确保私钥不进入应用层/页面/日志/响应。
5. `websites/{id}` 不存在时是 HTTP 200 + 业务码 500：服务层按 `record not found` 映射为 404 语义。
6. 证书申请（`ssl/obtain`）是 ACME 异步流程，可能超出内核单节点 120s 执行预算；超时后申请可能仍在 1Panel 后台执行，页面提示用户稍后刷新。
7. 域名端口：1Panel 域名条目可带端口（默认 80）；SSL 开关对 80 端口域名不可开启（1Panel 限制）。

## 5. 写操作处理器（IOperationHandler）

| Kind | 处理器 | 单节点风险 | 批量（>1 节点） | 1Panel 调用 |
|---|---|---|---|---|
| `website.start` | WebsiteStartHandler | Medium | Critical | `POST websites/operate`（start） |
| `website.stop` | WebsiteStopHandler | Medium | Critical | `POST websites/operate`（stop） |
| `website.update` | WebsiteUpdateHandler | Medium | Critical | `POST websites/update` |
| `website.php_version` | WebsitePhpVersionHandler | Medium | Critical | `POST websites/php/version` |
| `domain.create` | DomainCreateHandler | Medium | Critical | `POST websites/domains` |
| `domain.update` | DomainUpdateHandler | Medium | Critical | `POST websites/domains/update` |
| `domain.delete` | DomainDeleteHandler | **High** | Critical | `POST websites/domains/del` |
| `proxy.create` | ProxyCreateHandler | Medium | Critical | `POST websites/proxies/update`（create） |
| `proxy.update` | ProxyUpdateHandler | Medium | Critical | `POST websites/proxies/update`（edit） |
| `proxy.delete` | ProxyDeleteHandler | **High** | Critical | `POST websites/proxies/delete` |
| `proxy.status` | ProxyStatusHandler | Medium | Critical | `POST websites/proxies/status` |
| `ssl.apply` | SslApplyHandler | Medium | Critical | `POST websites/ssl/obtain` |
| `ssl.deploy` | SslDeployHandler | **High** | Critical | `POST websites/{id}/https` |
| `website.create` | WebsiteCreateHandler | **High** | 不支持（仅单节点） | `POST websites`（后台按 `taskID` 异步创建） |
| `domain.primary` | DomainPrimaryHandler | **High** | Critical | GET `websites/{id}` → `POST websites/update`（仅改 primaryDomain，保留其他字段） |
| `ssl.request` | SslRequestHandler | **High** | Critical | `POST websites/ssl`（创建记录）→ provider≠dnsManual 时 `POST websites/ssl/obtain` |
| `ssl.disable` | SslDisableHandler | **High** | Critical | GET `websites/{id}/https` → `POST websites/{id}/https`（enable=false） |

约定：

- `PlanAsync`：校验参数并生成 `Title/Summary/Risk/Targets/Warnings/TargetType`；`TargetType` 默认 `website`（`ssl.apply` 为 `ssl`，目标为证书）；
- 批量（节点数 >1）风险统一提升 Critical，强确认文本由内核默认生成（`N 个节点`）；单节点 High（删域名/删反代/SSL 部署/建站/设主域名/申请证书/关闭 HTTPS）需输入节点名确认。WEBSITE+ 中 `website.create` 与 `ssl.request` 的单节点强确认文本为 `"{域名} @ {节点名}"`，使确认同时覆盖域名与目标节点；`website.create` 明确拒绝多节点（`OperationValidationException`），避免一次性批量建站；
- `ExecuteAsync`：单节点执行，1Panel 返回业务错误映射为失败结果；`TargetId` = websiteId（SSL 申请为 sslId）；
- 参数校验：websiteId>0、域名格式（字母/数字/`*`/`-`/`_`/`.`）、代理名称/路径/目标（match 以 `/` 开头、proxyPass 为 http(s)）、端口 1~65535、httpConfig ∈ `HTTPSOnly|HTTPAlso|HTTPToHTTPS`、到期日期 `yyyy-MM-dd` 或 `9999-12-31`；
- **不记录敏感值**：执行结果 `DetailJson` 只含 id/operate/域名/开关等非敏感信息；内核审计 `DetailJson` 含 operationId/kind/title/risk/nodeName/targetId/success/message/taskId/durationMs（不含请求参数值）；
- 不自动重试/回滚（内核约束）。

## 6. 错误处理矩阵

| 场景 | 用户可见提示 | 处理 |
|---|---|---|
| 未选择节点 | 「请选择一个节点」 | 400（`WebsiteException(Validation)`） |
| 节点不存在 | 「节点不存在」 | 404（`NodeNotFoundException`） |
| 节点禁用 | 「节点 X 已禁用…」 | 400/502（Unsupported） |
| 1Panel 鉴权/网络/TLS/超时/内部错误 | 1Panel 或节点错误信息 | 502（`WebsiteException` 按 Kind 映射） |
| 网站不存在（record not found） | 「网站不存在或已被删除」 | 404 |
| 参数校验失败（本地） | 字段级中文提示 | `OperationValidationException` → 400，不生成确认 Token |
| 确认文本错误/Token 过期/重复提交 | 内核提示 | 409 + 审计 `operation.rejected` |
| 1Panel 写操作失败 | 逐节点失败原因 | 失败结果 + 审计 `operation.failed`，不重试/不回滚 |
| SSL 申请超时 | 提示稍后刷新证书状态/查看 1Panel 任务日志 | 内核超时失败；申请可能仍在后台执行 |
| 建站预检查不通过 | 展示预检查项（名称/状态/版本） | 向导阻止提交，不生成确认 Token |
| 建站/证书申请参数缺失 | 「主域名/运行环境/ACME 账户不能为空」等 | `OperationValidationException` → 400，不生成 Token |
| 域名已存在/1Panel 建站失败 | 1Panel 返回的业务错误 | 失败结果 + 审计 `operation.failed`，不自动回滚 |
| 分组读取失败 | 「无法读取网站分组…」警告，按未分组展示 | 降级，不阻断列表 |

## 7. UI 设计（`/websites`，中文）

```
页面头：标题「网站管理」 + 节点树按钮 + 刷新 + 「新建网站」（WEBSITE+）
```

## 8. 安全与审计

- 网站/域名/反代/HTTPS/DTO **不映射** SSL `privateKey`/`pem`，且 `WebsiteSslDto` 不使用 `JsonExtensionData`，避免私钥被扩展数据捕获后再次序列化；契约测试断言序列化结果不含私钥标记；
- WEBSITE+ 的 `WebsiteAcmeAccountDto` 只映射 id/email/type/status/isDefault，不映射 ACME `eabHmacKey` 等敏感字段；申请证书的 `detail` 只含域名/provider/证书 id；
- 页面只展示证书域名/状态/到期等安全元数据；不提供下载私钥/证书文件；
- 审计由内核统一写入：`operation.executed`/`operation.failed`/`operation.rejected`/`operation.batch`；`TargetType="website"`（SSL 申请为 `ssl`），`TargetId` 为 websiteId/sslId；
- API Key 仅经 `INodeSecretProtector` 解密并用于请求签名，不进入 DTO/日志/响应；
- 端点与页面 Admin only；真实节点只读探测，未执行任何写操作。

## 13. 遗留风险与限制

1. 真实节点网站数为 0：写接口与成功读响应只经源码核对 + 假面板验证；WEBSITE+ 真实节点只读复核了 `websites/options`（200，data=null）、`websites/check`（返回 OpenResty「应用未安装」，说明该节点当前无法建站）、`acme/search`（1 个 letsencrypt 账户）。首次真实验收需在含网站的节点做低危操作（编辑备注、启停测试网站、查看域名/反代/证书）。
2. 建站范围：WEBSITE+ 支持 `static/runtime(PHP)/proxy/subsite` 四类，不提供 `deployment`（应用部署）与 `stream`（流媒体）向导；建站是 1Panel 后台任务（`taskID`），提交成功不等于网站立即可用，需稍后刷新；不删除网站。
3. SSL 申请为 ACME 异步流程，可能超过内核 120s 执行预算；超时后申请可能仍执行，界面提示以证书列表状态为准；`dnsManual` 只创建证书记录，需用户手工加 DNS 后另行申请；申请失败不会自动删除已创建证书记录。
4. 域名新增后需用户自行确保 DNS 解析；开启域名 SSL 需先部署证书；「设为主域名」通过 `websites/update` 只改 `primaryDomain` 并保留备注/分组/到期等字段，但可能影响访问入口与证书匹配。
5. 反向代理仅管理常用字段（名称/路径/目标/Host/缓存开关/SNI/证书校验/CORS），不提供 `content` 源码级编辑。
6. PHP 版本切换仅对 `runtime` 类型或 `runtimeType=php` 的网站展示入口；运行环境列表来自 1Panel `runtimes/search`，需节点已安装 PHP。
7. 批量写操作已由内核支持（多节点 Critical/失败停止），本页默认单节点操作；`website.create` 明确只允许单节点。
8. 列表分组合并为多次 1Panel 查询（按分组），分组很多时略慢；单节点合并上限 1000 行并有截断提示。
9. 网站日志仅提供跳转链接，日志页面/内容由 P10（日志模块）负责。
10. 建站预检查（`websites/check`）依赖节点已安装 OpenResty 等基础应用；预检查不通过时向导阻止提交，不生成确认 Token；此时给出 `/appstore?app=openresty` 安装指引。
11. 域名仅支持新增/删除/SSL 开关/设为主域名；1Panel `websites/domains/update` 只接受 `{id, ssl}`，**不支持域名重命名或端口修改**，UI 不提供对应入口。
12. SSL 证书列表使用节点级 `websites/ssl/list`，未按 websiteID 过滤（只读服务 `GetSslCertificatesAsync` 无该参数）；关闭 HTTPS 与当前状态取自 `GET /websites/{id}/https`；证书删除无聚合 handler。
13. SSL 申请当前为 `websites/ssl` 创建后直接 `websites/ssl/obtain`，未单独调用 `websites/ssl/resolve` 显式校验 DNS；DNS 未就绪时由 obtain 返回 1Panel 错误，界面提示稍后重试或到 1Panel 处理。
14. 风险等级偏差（记录）：api-prober 建议 `website.create/update`、SSL 申请/部署为 Medium、域名/反代 Low-Medium；当前内核 `website.create`/`ssl.request`/`ssl.disable` 为 High，删除类按内核规则为 High（建站 High 为 task-25 规格要求）。本任务未改后端，待 Lead 决定是否统一下调。

## 14. 验收步骤（可复现）

1. 启动 PanelFleet，Admin 登录，侧边栏进入「网站管理」；
2. 选择节点 → 左侧分组树出现「全部网站」与 1Panel 分组；点击分组过滤列表，搜索域名/别名/备注；
3. 点击网站状态徽标 → 预览（Medium）→ 确认执行 → 结果视图 + 审计记录（`operation.executed`，targetType=website）；
4. 「编辑」→ 修改备注/收藏/到期/分组 → 预览 → 执行 → 列表刷新；
5. 「详情」抽屉：查看基础信息/域名/反代/HTTPS/证书；新增域名（预览 执行）、切换域名 SSL、删除域名（High，输入节点名确认）；
6. 反代：新增/编辑/启停/删除（删除为 High）；HTTPS：部署证书（High，选择证书与 HTTP 访问方式）；证书列表可发起申请（异步，提示稍后刷新）；
7. WEBSITE+ 建站：点「新建网站」→ 选节点/类型/主域名 → 运行环境或端口 → 预览（High，确认文本「域名 @ 节点」）→ 执行；成功提示 1Panel 后台创建，稍后刷新；节点未安装 OpenResty 时预检查会阻止提交；
8. 详情抽屉：查看创建时间/SSL 状态/反代数量，点「1Panel」打开节点对应网站页；域名行点「设为主域名」（High，确认后刷新）；HTTPS 区「申请证书」（选 ACME 账户/provider，成功后提示异步颁发）与「关闭 HTTPS」（High）；
9. PHP 网站显示「PHP 版本」区块，可切换运行环境（预览 执行）；
10. 批量验证（API）：`POST /api/operations/preview` 多节点 `website.start` → Critical、确认文本「N 个节点」→ 执行后 `operation.batch` 审计；

12. WEBSITE+ 只读端点：`GET /api/websites/{nodeId}/create-options|precheck|acme-accounts` 返回节点真实数据。
