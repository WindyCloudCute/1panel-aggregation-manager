## 1. 目标与非目标

**目标**

1. 在一个页面查看四类日志：**面板日志（操作/登录）、系统日志（journalctl）、容器日志、网站日志**；
2. 跨节点查询：按节点过滤或全部启用节点；逐节点并发受**并发/超时/预算**限制；单节点失败不影响其他节点；
3. 统一查询：范围、节点、时间范围、关键字、行数上限；容器/网站上下文参数（容器名、网站域名）；
4. **大日志保护**：行数上限（默认 200、最大 2000）、单行长度上限 8 KiB、单节点总字节上限 1 MiB；超限明确标记「已截断」；
5. 只读：不提供清空、下载、删除、实时无限流；不落盘日志内容；
6. `/logs` 支持 P6/P7 页面跳转 query：`type=panel|system|container|website&nodeId=<guid>&container=<name>&website=<domain>`。

**非目标**

- 实时跟随/tail -f（WebSocket/SSE 无限流）——P6 已有容器日志一次性 tail，P10 起不做实时日志；
- 日志下载/导出、清空日志、按时间轴检索大文件（1Panel 接口不支持逆向分页的日志范围）；
- 日志采集入库、全文索引、审计日志（审计见 `audit` 表与 `/audit` 页面）；
- 跨节点日志合并排序（多节点按节点分组展示，避免时间与时区误导）。

## 2. 真实接口探测结论（1Panel v2.3.2）

> 探测对象：内网真实 1Panel 节点（地址脱敏），2026-11-17；**全部只读**。源码核对：1Panel 官方 tag `v2.3.2` 的 `core/router/ro_log.go`、`agent/router/ro_log.go`、`agent/app/api/v2/logs.go`、`agent/app/dto/logs.go`、`core/app/api/v2/logs.go`、`core/app/dto/logs.go`、`agent/app/dto/request/website.go` 与前端 `frontend/src/api/modules/{log,website}.ts`。

### 2.1 路由与鉴权

| 项目 | 结论 |
|---|---|
| core API 前缀 | `/api/v2/core/**`（面板操作/登录日志） |
| agent API 前缀 | `/api/v2/**`（系统日志、网站日志、容器日志） |
| 鉴权 | 现有 HMAC 头 `1Panel-Token`/`1Panel-Timestamp` 对 core/agent 均有效 |
| 方法 | 面板/系统/网站日志查询均为 **POST 查询**（只读）或 GET；无副作用 |

### 2.2 接口汇总

| 范围 | 接口 | 请求关键字段 | 响应关键字段 | 实测 |
|---|---|---|---|---|
| 面板操作日志 | `POST /api/v2/core/logs/operation` | `{page,pageSize,source?,status?,node?,operation?}` | `data.{total,items[]}`：`id,source,user,ip,path,method,userAgent,status,message,detailZH,latency(纳秒),createdAt` | total=169 |
| 面板登录日志 | `POST /api/v2/core/logs/login` | `{page,pageSize,info?,status?,startTime?,endTime?}` | `data.{total,items[]}`：`id,ip,user,address,agent,status,message,createdAt` | total=31 |
| 系统日志状态 | `GET /api/v2/logs/system/status` | – | `{source,version,keywordFilterSupported,message}` | journalctl、systemd 257、支持关键字 |
| 系统日志文件 | `GET /api/v2/logs/system/files` | – | `string[]`（可用日期，如 `2026-11-16`） | 23 天 |
| 系统服务列表 | `GET /api/v2/logs/system/services` | – | `string[]`（`*.service`） | 14 个 |
| 系统日志读取 | `POST /api/v2/logs/system/read` | `{pageSize(1..500),cursor?,startTime?,endTime?,keyword?,priority?,service?}` | `{source,items[],hasMore,nextCursor}`；item：`time,priority,service,message,raw` | 正常返回；`raw` 为 journal 完整 JSON |
| 网站列表（解析 id） | `POST /api/v2/websites/search` | `{page,pageSize,name,orderBy,order}` | `items[]`：`id,primaryDomain,alias` | 节点 0 网站 |
| 网站日志 | `POST /api/v2/websites/log/search` | `{id,logType:"access.log"\|"error.log",page,pageSize}` | `{enable,content,end,path}` | 无网站时 500 record not found |
| 容器日志 | `GET /api/v2/containers/search/log?container=&since=&tail=&follow=false&timestamp=` | SSE | `data:` 行 | 复用 P6 `IContainerLogClient`；节点 8 容器 |

### 2.3 关键约束

1. **系统日志 `raw` 字段**是 journal 的完整 JSON（可能含命令行、环境变量等敏感内容）。本模块 DTO **不映射 raw**（契约测试用反射断言 DTO 无 `Raw` 属性），页面/API 只展示 `time/priority/service/message`；
2. 系统日志服务端支持 `keyword/priority/service/startTime/endTime` 过滤；`keyword` 依赖 journalctl 版本（状态接口 `keywordFilterSupported`），本模块同时做客户端兜底过滤；
3. 系统日志分页用 `cursor` + `hasMore/nextCursor`（本页只取首页，页面提示「还有更多」）；
4. 面板操作日志不支持时间范围/关键字参数 → 本模块对返回页做客户端过滤（并提示范围有限）；
5. 网站日志必须先拿到数字 `id`：若 `website` 参数是域名，本模块先 `POST websites/search` 精确匹配 `primaryDomain/alias`，再读日志；节点无网站时按节点错误展示；
6. 容器日志仍走 P6 的 SSE 客户端（一次性 tail、非跟随），沿用其 2000 行/1 MiB 上限。

## 3. 页面与交互（`/logs`）

```
系统日志                                           [查询日志]
筛选卡片：
  范围(面板/系统/容器/网站) · 节点(全部启用节点/单节点)
  面板→面板日志(操作/登录)
  系统→服务(下拉) · 级别(错误/警告/通知/信息/调试)
  容器→容器名(输入)
  网站→网站域名或 id(输入) · 网站日志(访问/错误)
  时间范围(全部/15m/1h/4h/24h) · 关键字 · 行数上限(200/500/1000/2000) [查询]
结果：每节点一块（成功/失败徽标、行数、耗时、匹配数、已截断/还有更多）
  失败节点：错误提示（不影响其他节点）
  成功节点：深色等宽日志查看器（时间 [级别] (服务) 消息 + 详情缩进）
```

- 首次进入按 query 参数初始化并自动查询（P6/P7 跳转）；
- 系统范围首次/切换节点时加载过滤选项（服务、文件日期）；
- 容器/网站范围缺少上下文参数时前端先提示，服务端仍会返回 400；
- 结果按节点分组，不跨节点排序（避免节点时钟不一致造成误导）。

## 4. 统一模型与截断策略

```csharp
public enum LogScope { Panel, System, Container, Website }

public sealed record LogQuery(
    LogScope Scope,
    Guid? NodeId = null, string? Container = null, string? Website = null,
    string PanelLog = "operation", string LogType = "access",
    DateTimeOffset? StartTime = null, DateTimeOffset? EndTime = null,
    string? Keyword = null, int? Limit = null,
    string? Service = null, string? Priority = null, string? Cursor = null);

public sealed record LogEntry(
    string? Time, string? Level, string? Service, string Message, string? Detail,
    DateTimeOffset? Timestamp = null);

public sealed record LogNodeResult(
    Guid NodeId, string NodeName, LogNodeState State,
    IReadOnlyList<LogEntry> Entries, bool Truncated, long? Total, bool HasMore,
    string? NextCursor, PanelError? Error, string? ErrorMessage, TimeSpan Elapsed);

public sealed record LogQueryResult(
    LogScope Scope, IReadOnlyList<LogNodeResult> Nodes,
    int NodesTotal, int NodesSucceeded, int NodesFailed, int TotalEntries,
    int Limit, string? Keyword, string? Container, string? Website,
    string? PanelLog, string? LogType, DateTimeOffset? StartTime, DateTimeOffset? EndTime,
    DateTimeOffset GeneratedAt);

public sealed record LogFilterOptions(
    IReadOnlyList<string> Services, IReadOnlyList<string> Files,
    int NodesTotal, int NodesFailed, DateTimeOffset GeneratedAt);
```

**截断策略（每节点独立）**

| 限制 | 默认值 | 行为 |
|---|---|---|
| `Limit`（行数） | 200（请求可调，最大 2000） | 超出丢弃并标记 `Truncated` |
| 单行长度 | 8192 字符 | 截断加 `…`，标记 `Truncated` |
| 单节点总字节 | 1 MiB（UTF-8） | 超出停止累加，标记 `Truncated` |
| 系统日志页大小 | 1Panel 上限 500 | `limit>500` 时只取 500 行并提示「还有更多」 |
| 容器日志 | P6 SSE 客户端 2000 行 / 1 MiB | 双重截断标记 |

**级别映射（系统日志 priority）**：0 紧急 / 1 警报 / 2 严重 / 3 错误 / 4 警告 / 5 通知 / 6 信息 / 7 调试。

## 6. Application 层

### 6.1 类型

- `ILogService.QueryAsync(LogQuery, CancellationToken)`：跨节点查询；
- `ILogService.GetFilterOptionsAsync(Guid? nodeId, CancellationToken)`：系统日志服务/文件选项；
- `LogValidationException`（Web 400）、`LogNodeNotFoundException`（Web 404）；
- `LogOptions`（见配置项）；`AddLogModule(this IServiceCollection)` 幂等注册。

### 6.2 查询流程

```
ResolveNodesAsync:
  nodeId 指定 → 必须存在且启用（否则 LogNodeNotFoundException）
  未指定 → 全部启用节点

QueryAsync:
  校验范围参数（容器需 container、网站需 website、start<=end）
  limit = clamp(query.Limit ?? 200, 1, Logs:MaxLines)
  整轮预算 Budget + 并发信号量 MaxConcurrency
  每节点：NodeTimeout 超时 + 独立异常隔离
    面板：POST core/logs/operation|login（pageSize≤200）→ 映射 + 客户端关键字/时间/上限过滤
    系统：POST logs/system/read（pageSize≤500）→ 映射 + 客户端兜底过滤 + hasMore
    容器：IContainerLogClientFactory → SSE 一次性 tail（since 取 startTime）
    网站：域名→websites/search→id→websites/log/search→按行拆分（tail 取最后 limit 行）
  汇总：NodesTotal/Succeeded/Failed、TotalEntries、Limit、查询条件回显
```

- 并发与预算：`SemaphoreSlim(MaxConcurrency)` + `CancellationTokenSource.CancelAfter(Budget)`；等待槽位/节点超时的失败以节点错误返回，不抛出整轮失败（调用方取消除外）；
- 安全：不写数据库/不落盘；不记录 API Key；系统日志 raw 不进入 DTO/响应。

## 11. 错误矩阵

| 场景 | 用户可见提示 | 日志级别 | 处理 |
|---|---|---|---|
| 未知 `type` | 未知日志范围 type，支持 panel/system/container/website。 | Information | 400 |
| 容器范围缺 container | 容器日志查询需要指定容器名（container）。 | – | 400 |
| 网站范围缺 website | 网站日志查询需要指定网站域名或 id（website）。 | – | 400 |
| start > end | 开始时间不能晚于结束时间。 | – | 400 |
| 节点不存在/禁用 | 节点不存在或已禁用（guid）。 | Information | 404 |
| 单节点不可达/超时 | 节点结果块显示失败原因（含 `PanelError`） | Warning | 该节点失败，其他节点正常 |
| 整轮预算用完 | 整轮查询预算已用完，未执行该节点。 | Warning | 节点失败结果 |
| 网站域名未匹配 | 节点未找到网站「xxx」。 | Warning | 节点失败 |
| 日志超限 | 已截断徽标 / 还有更多提示 | – | 按上限截断 |
| 1Panel 关键字过滤不支持 | 服务端返回错误 → 节点失败提示，可清空关键字重试 | Warning | 节点失败 |

## 12. 安全

- 只读：无清空/下载/删除接口；
- 不落盘：日志内容只在内存与 HTTP 响应中；
- 不映射系统日志 `raw`（journal 完整 JSON 可能含环境变量/命令行），契约测试断言；
- 不记录 API Key/Token；面板操作日志不展示 `apiKeyID/apiKeyName/userAgent`（只展示用户、IP、方法、路径、中文详情、耗时）；
- 日志内容可能含敏感信息：页面提示为「诊断用途」，不提供导出/外链；
- 真实节点验收只读，不触发写接口。

## 15. 风险与未决问题

| 风险 | 影响 | 对策 |
|---|---|---|
| 面板操作日志不支持时间/关键字过滤 | 只能过滤返回页，历史检索有限 | 页面提示；大范围建议用系统 journal |
| 系统日志依赖 journalctl | 部分系统返回 file 模式或关键字不可用 | 状态接口判断；失败按节点提示 |
| 系统日志单页上限 500 | 一次最多 500 行 | `limit>500` 时提示「还有更多」，可缩小时间范围 |
| 网站日志需先解析网站 id | 域名模糊匹配可能匹配错 | 精确匹配 `primaryDomain/alias` 优先，唯一结果兜底；否则报未找到 |
| 大日志占用页面内存 | 浏览器渲染变慢 | 行数/单行/字节三重上限，默认 200 行 |
| 日志内容含敏感信息 | 泄露风险 | 不落盘、不导出、raw 不映射；Admin only |
| 跨节点时钟不一致 | 合并排序误导 | 按节点分组展示，不合并排序 |
| 目录名 `Logs` 被 `.gitignore` 的 `logs/` 规则（Windows 大小写不敏感）忽略 | 提交时日志模块文件可能漏提交 | 提交时用 `git add -f src/PanelFleet.Application/Logs src/PanelFleet.Client/Dto/Logs src/PanelFleet.Web/Components/Logs tests/PanelFleet.Client.UnitTests/Logs`，或后续调整 .gitignore |
