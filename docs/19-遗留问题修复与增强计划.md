## 2. 关键设计决策

1. **不造假写操作**：所有真实变更必须经现有写操作内核（预览 → 强确认 → 逐节点顺序执行 → 任一失败停止 → 审计），禁止 UI 直连 1Panel 写接口。
2. **危险操作分级**：建站/删域名/删反代/SSL 部署/Compose 删除为 High 或 Critical；应用升级 High；面板改端口/安全入口**不自动执行**（会断连），UI 仅提示去 1Panel 操作。
3. **批量升级语义**：1Panel 无批量升级接口时，按「节点 × 应用」串行调用同一升级接口；批次摘要单独审计（`operation.batch`），每项记录 `operation.executed/failed`；无自动重试/回滚。
4. **资源页合并**：保留只读查询服务与端点（供总览/管理页复用），仅删除重复的页面与展示组件；旧链接重定向，避免书签失效。
5. **设置热更新**：PanelFleet 设置以 SQLite 覆盖层 + `IOptionsMonitor` 热生效；1Panel 面板设置永远实时读取，不缓存写入结果。
6. **真实节点边界**：探测与验收仅执行只读接口；写操作验收使用假面板/集成测试，或在用户明确许可的低危对象（测试库/测试计划任务）上执行。

## 8. 修复记录：fixed 浮层被内容区锚定（问题 1/2/4 的共同根因，任务 22/28）

**现象**：容器页长列表下，批量确认框、日志面板、详情抽屉被定位到内容区而非视口（实测 800px 视口内对话框 y=1382，backdrop 高 2600）。

**根因（两条，实测于 Edge）**：

1. `.page-enter { animation: page-in ... both }` 的 keyframes 含 `transform: translateY(6px)`；即使末帧写 `transform: none`，`fill-mode: both` 下动画结束后 computed transform 仍是 `matrix(1,0,0,1,0,0)`（identity 仍非 `none`）→ `.page-enter` 成为内部 `position: fixed` 浮层的 **containing block**，浮层相对内容区定位。
2. `opacity` 动画 + `fill: both` 在动画结束后长期保留 stacking context → z-index 更高的 modal-backdrop（`--z-modal: 100`）被 sticky topbar（`--z-topbar: 50`）压住。

**修复决策**：页面入场动画只做 opacity 淡入（`page-fade`），不使用 `fill: both`；删除 6px 上移。`.workbench-tree` 同步改用 `page-fade`。全站浮层无需逐页 `<style>` hack（已清理 `OperationConfirmDialog`、`ContainersView` 的临时 hack）。

**约束沉淀**：以后新增页面进入动画不得使用 transform，也不得使用 `animation-fill-mode: both`；新增 fixed 浮层必须自带 viewport 级 backdrop。

## 11. 回归记录：总览节点卡磁盘进度条不可见（2026-11-17）

- 现象：总览卡片磁盘分区能看到路径、百分比与用量文字，但看不到进度条。
- 定位：用 `tools/OverviewProbe` 以 `HtmlRenderer` 离线渲染 `NodeCard`，结合 headless Edge 注入脚本取 computed style，发现进度条元素尺寸为 **0×0**（CPU/内存条正常 235×6）。父容器 `.disk-row-body` 实际是 `flex-direction: column; align-items: center`，而 `.disk-track` 拿到的是 `flex: 1 1 0%`。
- 根因：`wwwroot/app.css` 里残留 P3 时期的全局 `.disk-*` 规则（`.disk-row-body{align-items:center}`、`.disk-track{flex:1}` 等），是按“横向一行”布局写的；P20 组件化后 `Components/Overview/NodeCard.razor.css` 改为纵向列布局，但全局 `align-items:center` 仍生效把空元素宽度压成 0，`flex-basis:0%` 又把纵向高度压成 0，于是进度条虽然存在却不可见。
- 修复：删除 `app.css` 中整段遗留 `.disk-*` 全局规则（全仓仅 `NodeCard` 使用这些类，`grep` 确认）；在 `NodeCard.razor.css` 补齐 `.disk-row-body{align-items:stretch}`、`.disk-path{flex:1 1 auto;min-width:0}`、`.disk-percent/.disk-usage{flex:none}`、`.disk-track{flex:none;width:100%;height:6px;margin-top:0}`。
- 门禁：`tests/PanelFleet.Client.UnitTests/Ui/SourceHygieneTests.cs` 新增 `OverviewDiskBars_KeepLayoutGuards`：断言 `app.css` 不得再出现 `.disk-track`/`.disk-row-body`，且 `NodeCard.razor.css` 必须保留 `align-items: stretch`、`flex: none`、`width: 100%`。全量测试 515/88/168 全绿。
