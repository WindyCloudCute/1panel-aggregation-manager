# 15 数据库管理详细设计（P8）

- 版本：v1.0
- 状态：**实施中（P8）**
- 关联：[需求与范围](00-需求与范围.md) / [架构设计](01-架构设计.md) / [工作约束](02-工作约束.md) / [P5 写操作内核](09-P5-写操作内核详细设计.md) / [P4 只读资源清单](07-P4-只读资源清单详细设计.md) / [功能扩展路线图](08-功能扩展路线图.md)
- 真实探测时间：2026-11-17（1Panel **v2.3.2**；节点地址与 API Key 在本文中省略）

## 1. 目标与范围

在 P5 写操作内核之上实现数据库管理（MySQL / PostgreSQL / MongoDB，Redis 按能力）：

1. **实例与库**：跨节点采集「节点 → 实例 → 库」树；实例来自远程连接或本地应用安装；
2. **库管理**：查看库（名称/字符集/排序规则/描述/授权账号）、创建库（Medium）、删除库（**Critical，强确认文本=库名**）、修改描述（Medium）；
3. **用户与授权（MySQL）**：用户列表、创建用户（High）、删除用户（High）、重置用户密码（High）、授权/取消授权（High）；
4. **连接信息与状态**：实例来源（local/remote）、版本、地址；本地/应用实例可读运行状态（远程实例优雅降级）；
5. **Redis（按能力）**：实例列表、CLI 能力检查、状态/配置只读、配置更新（High）；
6. **写操作安全**：全部走内核（预览 → 确认 → 执行 → 审计），密码字段按 1Panel 要求 Base64 传输，任何密码/敏感值不进入 DTO 输出、日志或审计。

### 非目标（P8 不做）

- 数据库实例本身的创建/删除/升级（1Panel「外部数据库连接」与本地应用安装，属高危且不在范围）；
- 备份/恢复（1Panel 该节点路由中无独立数据库备份接口，避免误导，留给后续阶段评估）；
- MySQL 变量调优（`/databases/variables/update`）、远程访问开关（`/databases/change/access`）、root 密码修改（`/databases/change/password`）——这些仅对**本地/应用实例**有效，远程实例实测返回 500，P8 不实现；
- PostgreSQL/MongoDB 的用户/权限管理（1Panel 的 PG/Mongo 用户通过 bind/privileges 接口与库绑定，语义与 MySQL 用户不同；真实节点未安装 PG/Mongo，无法验收，P8 只做实例/库读写）；
- 数据库监控曲线、慢日志、表结构管理。

### 2.3 关键报文与安全发现

库列表（节选，已脱敏）：

```json
{"code":200,"data":{"total":5,"items":[
  {"id":5,"createdAt":"2026-10-05T02:54:40Z","name":"word_***","from":"remote","mysqlName":"MySQL",
   "format":"utf8mb4","collation":"utf8mb4_0900_ai_ci","username":"","password":"","permission":"","isDelete":false,"description":""}
]}}
```

用户/授权（节选）：

```json
{"code":200,"data":[{"username":"app_***","host":"%","password":"","description":"","isDelete":false}]}
{"code":200,"data":[{"database":"app_***","username":"app_***","host":"%"}]}
```

Redis CLI 检查：`{"code":200,"data":false}`（节点未安装 redis-cli，Redis 配置能力不可用）。

**安全发现**：

1. 库/用户列表响应包含 `password` 字段（实测为空，但字段可能携带敏感值）——本模块 **DTO 不映射 password**、不使用 `JsonExtensionData`，从源头保证不会把密码带到 Web/日志/审计；
2. 创建/改密接口要求 `password` 字段为 **Base64**（`agent/app/api/v2/database_mysql.go` 使用 `base64.StdEncoding.DecodeString`），前端 `encodeBase64Fields` 对应 `js-base64`（UTF-8）；本模块按 UTF-8 → Base64 编码，仅在请求体中出现，不落日志/审计；
3. `compose/search` 类似问题（P6 已处理）不涉及本模块；Redis 配置响应含 `requirepass` —— `RedisConfDto` 不映射，且无扩展数据；
4. 远程实例不支持状态/变量/远程访问/基础信息/Redis 配置（返回 500），服务层按能力优雅降级，不把 500 当节点故障。

### 2.4 前端/后端源码核对结论

- `Container...` 无关；数据库操作按引擎分路由（见 §2.2）；
- `MysqlDBCreate.permission` 为 MySQL 用户 host（`%`/`localhost`/自定义 IP，前端 `permissionIPs` 直接作为 permission）；
- `MysqlDBDelete.type` 校验为 `oneof=mysql mariadb mysql-cluster`；PG 为 `postgresql/postgresql-cluster`；Mongo 为 `mongodb`；
- `DatabaseInfo/BaseInfo/RedisConf` 含密码字段，前端有单独“显示密码”逻辑；本模块一律不返回。

## 3. 设计

### 3.1 写操作清单（内核 Kind / 风险）

| Kind | 引擎 | 风险 | 强确认文本 | 说明 |
|---|---|---|---|---|
| `database.create` | MySQL / PG / Mongo | Medium | — | 创建库；MySQL/PG 可同时创建用户，Mongo 必须带用户 |
| `database.delete` | 三引擎 | **Critical** | **库名** | 删除库及数据；`forceDelete`/`deleteBackup` 默认 false；删除前 UI 调用 del-check 展示关联资源 |
| `database.description_update` | 三引擎 | Medium | — | 修改库记录描述（不改数据） |
| `database.user_create` | MySQL | **High** | 用户名 | 创建账号并可授予多个库 |
| `database.user_delete` | MySQL | **High** | 用户名 | 删除账号（所有授权一并清除） |
| `database.user_password` | MySQL | **High** | 用户名 | 重置账号密码，旧密码立即失效 |
| `database.grant` | MySQL | **High** | 库名 | 授予账号访问库 |
| `database.grant_revoke` | MySQL | **High** | 库名 | 取消授权 |
| `redis.config_update` | Redis | **High** | 实例名 | 更新 timeout/maxclients/maxmemory（仅本地实例） |

约束：

- **数据库写操作仅支持单节点**：预览时若 `nodeIds` 多于 1 直接抛"数据库写操作仅支持单节点执行"（避免跨节点误建同名库；批量场景由用户逐节点操作）；
- 参数中 `engine`、`instance` 必填；`instance`（实例名）沿用 Docker/1Panel 命名规则 `^[A-Za-z0-9][A-Za-z0-9_.-]{0,63}$`；
- 库名校验按引擎：MySQL `^[A-Za-z0-9_][A-Za-z0-9_$-]{0,63}$`、PG `^[A-Za-z_][A-Za-z0-9_]{0,62}$`、Mongo 禁止 `/ \ . " $ * < > : | ?` 空白与控制字符；
- 用户名 `^[A-Za-z0-9_][A-Za-z0-9_.-]{0,31}$`；host `^[A-Za-z0-9%._:/-]{1,255}$`；密码长度 1..128；
- 创建 PG 库必须提供用户名/密码；Mongo 必须提供用户名/密码/权限（`dbOwner|read|readWrite|userAdmin`）；MySQL 用户名可空（不建用户），填了用户名则密码必填；
- 删除库时 `id`（1Panel 记录 id）必填，`type` 取引擎（mysql/postgresql/mongodb）；
- 所有写操作不自动重试/回滚；密码只出现在请求体（Base64），不进入 `OperationStepResult.DetailJson`（只记录 operation/engine/instance/database/user）。

### 3.2 只读服务（`IDatabaseService`）

| 方法 | 1Panel 调用 | 说明 |
|---|---|---|
| `GetOverviewAsync(nodeId?)` | 每节点 4×实例列表 + 每实例 1×库列表 | 返回「节点 → 实例 → 库」；引擎/实例/节点失败独立隔离 |
| `GetUsersAsync(nodeId, instance)` | `POST /databases/users/search` | MySQL 用户 |
| `GetGrantsAsync(nodeId, instance)` | `POST /databases/grants/search` | MySQL 授权 |
| `GetFormatsAsync(nodeId, instance)` | `POST /databases/format/options` | 创建库弹窗字符集/排序规则 |
| `CheckDeleteAsync(nodeId, engine, id, instance)` | `POST /databases/{engine}/del/check` | 删除前关联资源（备份等） |
| `GetStatusAsync(nodeId, engine, instance, from)` | `POST /databases/status`（仅 `from=local`） | 远程实例返回 `Supported=false` + 原因 |
| `GetRedisInfoAsync(nodeId, instance, from)` | `GET redis/check` → status/conf/persistence | CLI 不可用或远程实例返回 `Supported=false` |

聚合语义：

- 跨节点并发受 `MaxConcurrency`（默认 4）限制；单节点超时 `NodeTimeoutSeconds`（默认 20s，因一个节点要串行拉 4 引擎 + 多实例）；
- 每实例最多 `PerInstancePageSize`（默认 200）条；超出标记 `DatabasesTruncated`；
- 未安装引擎（`data:null`）视为空；实例列表失败记录节点警告；节点所有引擎均失败 → `NodeGroup.Error`；
- 远程实例的 `from != local` 能力（状态/Redis 配置）不发起请求，直接返回不支持原因。

### 3.3 Client 层

- `DatabaseRoutes`：唯一路由定义处（含按引擎的 search/create/delete/del-check/description/root-password 与 MySQL 用户/授权/格式/状态/Redis 路由）；
- `Dto/Databases/DatabaseDtos.cs`：宽松解析 DTO + 请求记录；
  - **不映射 password**（库/用户/BaseInfo/RedisConf）；对密码可能出现的 DTO 不使用 `JsonExtensionData`，避免未知字段把敏感值带进内存对象；
  - 请求中密码字段统一命名 `password`（`[JsonPropertyName("password")]`），属性名 `PasswordBase64` 明示已编码；
- Base64 编码由 Application 处理器完成（`Convert.ToBase64String(UTF8.GetBytes(pwd))`），与 1Panel/Go 解码一致。

### 3.4 Application 层

- `Databases/DatabaseService.cs`：只读服务 + `DatabaseNodeNotFoundException`；
- `Databases/DatabaseOperationHandlers.cs`：9 个 `IOperationHandler` + `DatabaseOperationRules`（参数/名称/密码/单节点校验、Base64、计划构建、统一 POST 结果映射）；
- `Databases/DatabaseModels.cs`：引擎枚举、实例/库/用户/授权/状态/Redis 视图与只读结果包装；
- `Databases/DatabaseOptions.cs`：超时/并发/每实例条数；
- `Databases/DatabaseModule.cs`：`AddDatabaseModule(this IServiceCollection)`（幂等：检测 `DatabaseOptions` 已注册即返回）。

## 5. 错误矩阵

| 场景 | 用户可见提示 | 处理 |
|---|---|---|
| 1Panel 401/403 | `[节点] API Key 错误 / 面板拒绝访问` | 节点/实例隔离，其它节点正常 |
| 未安装引擎（PG/Mongo/Redis） | 不显示该引擎实例 | `data:null` 视为空，不报错 |
| 远程实例调用本地能力（状态/Redis） | `远程实例不支持…`（Supported=false） | 不发起 1Panel 请求 |
| 本地实例状态 500 | `1Panel 未返回实例状态…` + 错误详情 | 优雅降级，不阻断页面 |
| 删除检查失败 | `删除前检查失败：…` | 不进入预览，提示后重试 |
| 库/用户名不合法 | 预览阶段 400 | 内核 `OperationValidationException` |
| 缺少 id / 密码 / 实例 | 预览阶段 400 | 同上 |
| 多节点执行数据库写操作 | `数据库写操作仅支持单节点执行` | 预览拒绝 |
| 确认文本错误（删库/用户操作） | 页内错误/409 | 内核拒绝并写 `operation.rejected` |
| 节点不存在/禁用 | HTTP 404 | 端点返回 message |
| 1Panel 业务拒绝（如库名已存在） | `1Panel 拒绝执行：…` | step 失败，逐节点审计 |

## 9. 遗留风险与后续

| 风险/限制 | 说明 | 后续 |
|---|---|---|
| 远程实例能力受限 | 状态/变量/远程访问/Redis 配置仅本地实例可用（1Panel 返回 500） | UI 已按 from/Supported 降级；后续可显示"安装为本地应用"引导 |
| PG/Mongo 用户与权限 | 1Panel 语义为 bind/privileges，且真实节点未安装，P8 只实现库级读写 | 提供 PG/Mongo 实例后单独设计 |
| 备份/恢复 | 1Panel v2.3.2 数据库路由无独立备份接口（备份在应用/计划任务侧） | 不实现，避免误导；留给 P9/P10 或后续 |
| 密码前端 | 密码在浏览器内存与请求体中出现（Base64 非加密） | 与 1Panel 一致；HTTPS 部署必需；密码不落日志/审计 |
| 实例/库名称限制 | 采用保守正则，个别特殊字符（中文/空格）不支持 | 如需支持按引擎引号规则调整 |
| 删除关联资源 | del-check 返回的关联资源目前只做提示，不自动处理 | 后续可联动备份清理确认 |
| 数据量 | 每实例最多 200 库；超出只显示部分 | 需要时改为分页加载 |
| 单节点限制 | 数据库写操作不支持跨节点批量 | 与"避免误建同名库"的安全取舍一致 |
