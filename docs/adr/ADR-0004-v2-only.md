# ADR-0004 首版仅支持 1Panel v2

- 状态：提议（P0）
- 日期：2026-11-15
- 关联：[架构设计](../01-架构设计.md)

## 背景

1Panel v1 使用 `/api/v1` 与 MD5 签名；v2 使用 `/api/v2`，推荐 HMAC-SHA256（兼容 MD5），服务结构有较大变化（core/agent 拆分、新增 AI/任务/告警等模块）。首版同时支持两代会使适配层与测试矩阵翻倍。

## 决定

首版**只支持 1Panel v2.x**，API 前缀 `/api/v2`；鉴权同时实现 HMAC-SHA256（默认）与 MD5（Auto 回退，兼容旧 v2 小版本），但不对 v1 的接口差异做适配。

## 后果

- 优点：范围聚焦，适配与测试成本可控。
- 代价：v1 节点无法接入；老版本 v2（仅支持 MD5）由 Auto 回退覆盖。
- 若未来需要 v1，新增 `IOnePanelApiAdapter` 实现与版本探测，不改变上层 Application/Web；届时另写 ADR。
