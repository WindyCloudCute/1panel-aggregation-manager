## P1 骨架 + 客户端内核

**目标**：证明“能安全、正确地调用 1Panel v2 API”，并为后续所有功能打底。

**交付物**：
- 解决方案骨架（Domain / Client / Web / 测试项目；Application、Infrastructure 在 P2 创建）；
- `PanelRoutes`、`PanelRequest`/`PanelResponse`、`PanelError`、`NodeResult<T>`；
- `ApiKeySigningHandler`（HMAC/MD5、Auto 回退、Date 头时钟校准重试）；
- `EnvelopeDecoder`、`PanelErrorMapper`、`CapabilityProbe`；
- 最小 `DashboardClient`（base/os、current/node、base/{io}/{net}）；
- 进程内假 1Panel 服务与契约测试；
- 最小 Web 宿主（`/healthz`，不含 OIDC）。

**验收**：
- `dotnet build -c Release` 0 warning；
- `dotnet test -c Release` 全绿（覆盖签名向量、时钟偏差、鉴权回退、业务错误、gzip、超时、重定向）；
- 手工：`dotnet run` 后 `/healthz` 返回 200。

**明确不做**：数据库、登录、节点页面、并发聚合。

## P2 平台与节点管理

**详细设计**：[05-P2-平台与节点管理详细设计](05-P2-平台与节点管理详细设计.md)（已实现）

**目标**：能登录、能存节点、能验证节点可用性。

**交付物**：
- SQLite + EF Core + 初始迁移；
- DataProtection 密钥服务（API Key 加解密、脱敏提示）；
- OIDC 登录/登出 + 白名单授权（无本地密码）；
- 节点 CRUD 页面与 API（名称、地址、备注、标签、TLS 策略、API Key）；
- 连接测试（延迟、鉴权模式、时钟偏差、面板版本、能力）、健康巡检后台服务；
- 审计基础设施（登录、节点变更、测试连接）；
- 页面骨架（布局、导航、错误页、未授权页）。

**验收**：
- 未登录访问任意页面跳转 IdP；白名单外用户被拒绝；
- 新增 2 个节点（1 正常、1 错误 Key），测试结果分别正确；
- API Key 在数据库/日志/页面均为密文或末 4 位；
- 重启后已存节点仍可解密使用。

## P3 聚合总览

**详细设计**：[06-P3-聚合总览详细设计](06-P3-聚合总览详细设计.md)（已实现，2026-11-16）

**目标**：一屏看清所有节点。

**交付物**：
- `FanoutEngine`（并发上限、每节点超时、熔断、预算）；
- `OverviewService` + 快照缓存（TTL、Stale 标记）；
- SignalR 增量推送 + 前端卡片独立更新；
- 总览页：健康、CPU/内存/磁盘/负载、系统信息、资源计数、汇总条；
- 节点故障/超时/鉴权失败的明确提示与重试。

**验收**：
- 10 个假节点（其中 2 个超时、1 个返回 401）时页面 12s 内可用；
- 失败节点显示缓存数据与时间戳，或显示可操作错误；
- 单个慢节点不阻塞其它卡片。

**P3 完成记录**：139 个测试通过；真实节点（1Panel v2.3.2）首轮聚合刷新 434ms、健康 Online；集成性能用例 10 节点（2 慢 + 1×401）< 12s。详见详细设计 §18。

## P11 主机与容器终端

**详细设计**：`12-主机与容器终端详细设计.md`（含 WebSocket 协议探测）。

**交付物**：
- 浏览器 ↔ PanelFleet `/ws/terminal` ↔ 1Panel WS 双向桥；Admin only + Origin 校验 + 输入限流 + 空闲/最长时长；

- 审计 `terminal.session.start/end`（节点/模式/容器/操作者/时长/重连次数/输入输出字节，**不记录输入内容**）。

**完成记录**：测试 93 项（单元 84 / 集成 9）；真实节点主机终端与容器 exec 各执行 `echo`/`uptime` 后关闭，Auto 回退 MD5 验证成功，未执行破坏性命令。
